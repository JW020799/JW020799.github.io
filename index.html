Troubleshooting

잘 되는 결과보다, 틀리면 위험한 조건을 먼저 확인했습니다.

RAG 근거 부족 처리

문제: 일부 케이스에서 근거 문서가 부족해도 낮은 위험도로 출력될 가능성 확인

해결: UNKNOWN 3개 이상이면 FAILED 처리하도록 응답 기준을 정리했습니다.

PRICE 문서 오탐 방지

문제: 전체 통계 문서가 직접 가격 근거처럼 통과되는 케이스 확인

해결: STAT_DATA 문서를 직접 가격 근거에서 제외하고 평균 수리비 기준표 보강 대상으로 분리했습니다.

외부 API 실패 대응

문제: yfinance 호출 시 429 Too Many Requests로 재무 데이터 수집 실패

해결: 실패 상태를 명시적으로 반환하고 리포트 생성 흐름이 중단되지 않도록 fallback 구조를 적용했습니다.

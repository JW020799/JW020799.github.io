Project Overview

GIUT는 사용자가 지역, 날짜, 관심사에 따라 행사를 탐색하고, OpenAI API 기반 추천 코스를 받을 수 있도록 만든 서비스입니다. 공공데이터를 서비스 데이터로 활용하고 Docker Compose와 AWS EC2로 실제 배포까지 진행했습니다.

My Role

  • FastAPI 기반 회원가입/로그인 API 구현
  • 행사 검색 및 필터링 API 구현
  • 사용자 프로필 조회 및 수정 흐름 구현
  • 공공데이터 API와 서비스 데이터 흐름 이해
  • OpenAI API 기반 추천 기능 연동 흐름 경험
  • Docker Compose와 AWS EC2 배포 구조 학습

Result

Backend API

사용자 인증, 행사 조회, 검색/필터링 API를 구현하며 FastAPI 백엔드 흐름을 경험했습니다.

External API

공공데이터 API와 OpenAI API를 서비스 기능으로 연결하는 흐름을 학습했습니다.

Deployment

Docker Compose 기반으로 프론트엔드, 백엔드, MySQL을 함께 실행하고 EC2 배포를 경험했습니다.

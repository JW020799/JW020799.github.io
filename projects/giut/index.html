프로젝트 개요

GIUT Festival Guide는 전국 축제 정보를 기반으로 사용자가 지역, 날짜, 키워드에 맞는 행사를 탐색하고, GPT 추천 코스를 저장한 뒤 마이페이지에서 다시 확인할 수 있도록 만든 웹 서비스입니다. 단순 행사 목록 조회를 넘어 사용자 액션, 추천 코스 저장, 문의와 관리자 답변까지 연결하는 흐름을 목표로 했습니다.

핵심 기능

TourAPI 축제 조회

한국관광공사 TourAPI를 활용해 전국 축제 목록과 행사 상세 정보를 조회합니다.

검색 / 필터링

지역, 날짜, 키워드 조건으로 사용자가 원하는 축제를 빠르게 찾을 수 있게 구성했습니다.

GPT 추천 코스

지역, 날짜, 키워드 입력값을 바탕으로 조건에 맞는 추천 코스 3가지를 생성합니다.

저장 / 문의 / 알림

좋아요, 북마크, 리뷰, 코스 저장, 문의 답변, 알림 조회까지 사용자 기능으로 연결했습니다.

사용자 흐름

01

메인 탐색

사용자는 메인 화면에서 축제를 검색하고 필터를 적용합니다.

02

행사 상세

행사 상세 정보와 지도 위치를 확인하고 좋아요, 북마크, 리뷰를 남깁니다.

03

AI 추천

지역, 날짜, 키워드를 입력해 GPT 기반 추천 코스를 생성합니다.

04

저장 / 재확인

추천 코스를 저장하고 마이페이지에서 북마크와 저장 코스를 다시 확인합니다.

담당 구현 범위

  • 회원가입, 로그인, 로그아웃 API 구현
  • 이메일 / 닉네임 중복 확인 API 구현
  • JWT access token / refresh token 기반 인증 흐름 구현
  • HttpOnly Cookie 기반 인증 응답 구조 적용
  • 사용자 정보 조회 및 수정 API 구현
  • 마이페이지, 북마크, 저장 코스 조회 흐름 구현
  • 행사 검색 / 필터링 API 흐름 구현
  • 공공데이터 API와 GPT 추천 코스 기능의 서비스 흐름 이해 및 연동

시스템 아키텍처

Frontend

React / Vite / Tailwind CSS

사용자 화면에서 행사 탐색, 상세 조회, 추천 요청, 마이페이지 흐름을 제공합니다.

Backend

FastAPI / SQLAlchemy / Pydantic

인증, 사용자 기능, 행사 데이터, 추천 요청 API를 처리합니다.

Database

MySQL

사용자, refresh token, 행사 데이터, 북마크, 저장 코스, 문의와 알림 데이터를 저장합니다.

External API

OpenAI / TourAPI / Naver Map

GPT 추천, 한국관광공사 행사 데이터, 지도 위치 표시 기능을 외부 API로 연결했습니다.

문제 해결 과정

인증 상태 관리

PROBLEM

로그인 상태에 따라 마이페이지, 북마크, 코스 저장 같은 개인화 기능 접근을 제한해야 했습니다.

SOLUTION

access token과 refresh token을 분리하고, refresh token을 DB에 저장해 만료 시 재발급 흐름을 구성했습니다.

GPT 추천 결과 저장

PROBLEM

AI 추천 결과가 일회성 응답으로 끝나면 사용자가 나중에 추천 코스를 다시 확인하기 어려웠습니다.

SOLUTION

GPT가 생성한 추천 결과를 코스 단위로 저장하고, 마이페이지에서 저장 코스를 조회할 수 있게 연결했습니다.

TourAPI 데이터 저장

PROBLEM

외부 API를 매번 직접 호출하면 응답 속도와 안정성, 데이터 활용 흐름이 흔들릴 수 있었습니다.

SOLUTION

백엔드 서버에서 TourAPI를 호출하고, 행사와 상세 데이터를 MySQL 테이블 구조에 맞게 저장하는 흐름을 정리했습니다.

사용자 액션 연결

PROBLEM

좋아요, 북마크, 리뷰, 문의, 알림이 각각 분리되면 서비스 이용 흐름이 끊길 수 있었습니다.

SOLUTION

사용자 ID를 기준으로 개인화 데이터를 연결하고, 문의 답변 시 알림 상태를 함께 관리하는 구조를 이해했습니다.

프로젝트 결과

Auth / User API

JWT와 HttpOnly Cookie 기반 인증 흐름을 구현하고 개인화 기능의 기반을 만들었습니다.

Festival Data Flow

TourAPI 행사 데이터 조회, 상세 정보, 검색과 필터링 흐름을 서비스 기능으로 연결했습니다.

AI Course Recommendation

GPT 추천 결과를 코스 단위로 생성하고 저장해 사용자가 다시 확인할 수 있는 구조를 만들었습니다.

Project Overview

이 프로젝트는 뉴스 수집, 재무 데이터 수집, 임베딩, 벡터 검색, Agent 역할 분리, 리포트 생성까지 AI 서비스의 전체 흐름을 작게 구현해보기 위해 만든 데모입니다.

Implemented Features

  • Google News RSS 기반 기업 뉴스 수집
  • yfinance 기반 재무 데이터 수집 및 fallback 처리
  • Sentence-Transformers 기반 문서 임베딩
  • ChromaDB 기반 벡터 저장 및 유사도 검색
  • Planner, RAG, News, Finance, Risk, Report 역할 분리
  • FastAPI API와 Streamlit 화면 구성
  • 외부 데이터 호출 실패 시에도 리포트 흐름이 중단되지 않도록 예외 처리
  • GitHub 포트폴리오용 README 및 구조 정리

Technical Point

RAG Search

뉴스 문서를 임베딩하고 코사인 유사도 기반으로 관련 문서를 검색했습니다.

Agent Workflow

하나의 LLM 호출이 아니라 역할별 처리 단계를 분리해 리포트 생성 흐름을 구성했습니다.

Service Demo

Streamlit과 FastAPI를 함께 사용해 빠르게 검증 가능한 데모 형태로 구현했습니다.

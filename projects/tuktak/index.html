Project Overview

TUKTAK은 사용자가 수리 대상 사진과 자연어 설명을 입력하면 AI가 수리 요청을 구조화하고, 예상 견적과 리스크 리포트, 시공자 매칭까지 이어주는 서비스입니다. 단순 매칭이 아니라 사용자가 수리 전에 참고할 수 있는 가격 기준과 위험 요소를 함께 제공하는 데 초점을 두었습니다.

My Role

  • Risk Report 도메인 모델 및 API 구조 구현
  • Main Backend와 AI Service 연동 구조 정리
  • ChromaDB 기반 RAG 문서 검색 흐름 설계 및 구현
  • RAG 검색 결과의 UNKNOWN / FAILED 예외 기준 정리
  • 이미지 유사사례 검색 threshold 설계
  • Nomic Embed Vision 기반 이미지 임베딩 검색 구조 검토
  • Ko-SRoBERTa 기반 문서 임베딩 모델 선정 검토
  • 발표 자료 및 시연 영상 제작 참여

Architecture Focus

AI Estimate

사진과 설명을 구조화한 뒤 유사사례와 기준 데이터를 바탕으로 견적 흐름을 구성했습니다.

Risk Report RAG

공공기관/소비자원/표준시방서 기반 문서를 임베딩해 리스크 근거 문서를 검색하도록 설계했습니다.

Reverse Matching

AI 견적서를 기준으로 시공자가 제안하고 사용자가 비교 선택하는 흐름으로 연결했습니다.
